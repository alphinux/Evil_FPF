### 🚀 Installation and Run Guide

```bash
# Update the environment
apt update && apt upgrade -y || (pkg update && pkg upgrade -y)

# Install Python and Git (if not installed)
apt install git python3 python3-pip -y || pkg install git python -y

# Clone the repository
git clone https://github.com/alphinux/Evil_FPF-v1.0-.git

# Navigate into the directory
cd Evil_FPF-v1.0-

# Install required dependencies
pip install flask

# Run the tool
python3 evilfp.py
```
